# exs-py

Mais de 300 exercícios de Python para praticar programação e lógica

Os exercícios foram coletados de diferentes fontes, como sites, livros e outros materiais

## Organização
`/all` -> Todos os exercícios separados por pastas  
`/dunossauro` -> Exercícios específicos do [dunossauro](https://exercicios.dunossauro.com/)  
`main.py` -> Todos os exercícios num único arquivo
